게임

미니게임 9종의 규칙·조작과 공통 게임 구조

1. 프로젝트 개요

브라우저에서 바로 하는 과일 테마 미니게임 모음입니다. 로비 하나에서 9개 게임을 고르고, 모든 판의 결과가 레벨·미션·업적·코인·랭킹으로 이어집니다. 로그인 없이도 전부 플레이할 수 있고, Google 로그인하면 기록이 기기 사이에 동기화되고 랭킹·친구 기능이 열립니다.

로비

게임 타일(최고 기록 · 플레이 수), 종류 필터 칩, 내 레벨, 연속 출석, 오늘의 미션, 최근 플레이

설치형 앱

홈 화면에 설치, 한 번 열어 두면 인터넷 없이 게임 가능(로그인·랭킹 제외)

테마 · 접근성

라이트 · 다크 · 시스템 테마, “동작 줄이기” 존중, 키보드만으로 모든 메뉴 사용

같은 그림

과일·게임 이모지를 앱에 내장한 그림으로 그려 휴대폰에서도 PC와 똑같이 보임

2. 게임 라인업

게임핵심 규칙조작랭킹
과일 메모리같은 과일 카드 짝 맞추기. 4×4 · 6×6 · 8×8 타임어택 · 8×8 조커, 콤보 보너스, 오답 감점클릭 · 터치, H 플래시 힌트, C 카드 힌트있음
수박 게임같은 과일끼리 합쳐 수박 만들기. 망치 · 흔들기 아이템, 넘침 선 위 5초면 끝← → / A D, Space 낙하, 1 망치, 2 흔들기있음
FRUIT DASH떨어지는 과일 피하며 황금 별 모으기. 쉬움 · 보통 · 어려움, 방패 · 자석 · 느림 · 점수 2배← → / A D, 마우스 · 터치있음
과일 퍼즐매치-3. 클래식(이동 30번 · 랭킹)과 목표가 있는 스테이지 30개, 줄 폭탄 · 큰 폭탄, 연쇄 보너스밀기 · 두 칸 차례로 누르기, 방향키 + Enter있음
과일 자르기날아오르는 과일을 그어서 자르기. 3개 이상 콤보, 황금 별 +50, 얼음(느린 시간), 하트(회복), 폭탄. 난이도 3단계누른 채 긋기 · 손가락으로 밀기있음
과일 피아노내려오는 타일을 아래부터 눌러 연주. 저작권이 끝난 13곡, 왼손 반주, 긴 타일, 완주마다 빨라짐터치 · 클릭, D F J K있음
과일 주스 가게손님 주문대로 과일을 믹서에 넣어 주스 만들기. 순서 무관, 빠르고 연속일수록 고득점, 화난 손님 3번이면 끝터치 · 클릭, 1–8 Enter Backspace있음
과일 점프달리는 과일로 선인장 · 돌 · 버섯 · 벌 넘기. 길게 누르면 더 높이, 체리 +20, 점수에 따라 낮 · 밤터치 · 클릭, Space ↑ ↓있음
과일 그리기1~6명이 한 화면을 돌려 가며 제시어 과일 그리기. 싱크율(0~100%)로 채점, 라운드 1등 1점터치 · 마우스없음 (파티 게임)

공통 조작: ESC 일시정지 · 창 닫기, Space · Enter 게임 시작. 처음 여는 게임은 짧은 방법 안내가 나오고, 시작 화면의 ? 버튼으로 다시 봅니다.

3. 수박 게임

  • 물리 직접 구현, 120Hz 고정 틱이라 어느 기기에서나 똑같이 움직임. 병 크기 528×720(논리 단위)
  • 체리에서 시작해 같은 과일이 닿으면 한 단계 큰 과일. 수박끼리는 합쳐지지 않고 결과 카드에서 개수를 셈
  • 망치(고른 과일 부수기) · 흔들기(병 섞기): 한 판에 2개씩, 합체 10번마다 하나 더, 종류마다 5개까지
  • 30초마다 점수 배율 +0.1(5분이면 2배), 시간이 갈수록 큰 과일이 자주 나옴
  • 넘침 선 위에 5초 넘게 머물면 끝. 게임 오버 뒤에도 4초 동안 물리가 마저 가라앉음
  • 떨어지는 과일 순서는 시드로 정해져 친구 대결에서 같은 판을 재현

중간이 예전 게임과 같아서 이전 기록과 그대로 비교됩니다. 친구 대결 링크에도 난이도가 실리고, 예전 링크는 중간으로 고정됩니다. 하트는 목숨이 가득하면 맞은 폭탄 하나를 지워 줍니다.

5. 신작 게임 상세

과일 피아노

반짝반짝 작은 별부터 엘리제를 위하여까지 13곡. 원본 악보의 음과 박자를 따르고 곡마다 왼손 반주가 붙습니다. 긴 음은 꾹 누르는 긴 타일, 한 곡을 완주할 때마다 빨라지고, 빈 칸을 누르거나 타일을 놓치면 끝. 곡 목록은 카드 형태.

과일 주스 가게

손님은 정해진 자리에 앉아 과일 조합을 주문하고, 인내심 막대가 줄어듭니다. 믹서에 넣은 과일은 주문표에 ✓로 표시되고 병 속 색이 섞입니다. 맞는 주스는 빨리 줄수록 점수가 크고, 틀리면 손님의 인내심이 깎입니다. 레벨마다 과일 칸이 하나씩 열리고 주문이 커집니다.

과일 점프

장애물 달리기. 선인장 · 돌 · 버섯 장애물과 낮게 · 높게 나는 벌, 체리. 공중에서 ↓로 빨리 내려오고, 갈수록 빨라지며 점수에 따라 낮과 밤이 바뀝니다.

과일 그리기

펜 · 채우기 · 지우개 · 되돌리기. 그림이 진짜 과일 그림과 모양 · 색 · 위치가 얼마나 닮았는지 싱크율로 잽니다. 랭킹 · 점수 서버 · 대결 링크가 없는 파티 게임이고, 점수판은 % 로 표시합니다.

6. 공통 게임 구조 · 새 게임 추가

한 판의 흐름

  1. 시작 카드방법 안내, 난이도 · 모드 선택, 최고 기록
  2. 판 진행공용 게임 틀과 HUD. 판이 시작되면 onRoundChange(true)
  3. 판 종료onGameComplete({ game, score, seconds })를 한 번만 호출 → 앱이 경험치 · 코인 · 미션 · 업적 · 순위를 계산해 돌려줌
  4. 결과 카드신기록, 얻은 경험치, 완료한 미션, 순위(“오늘 3위 · 전체 23위”), 결과 이미지 저장 · 공유

새 게임을 넣을 때

  1. 화면 · 게임 종류와 통계 필드(<게임>PlayCount, <게임>HighScore) 추가
  2. 게임 정보 목록 GAMES · 순서 · 화면 매핑에 등록
  3. 게임 컴포넌트 작성: settings, isPaused, onUnlockAchieve, onGameComplete, onRoundChange, onExit를 받음
  4. 앱에 나눠 불러오기 등록, 미션 · 대결 링크 · 상점 코인 비율 · 배경음악 · 업적 탭 채우기
  5. 랭킹 게임이면 RANKED_GAMES에 넣고, 보안 규칙의 보드 id와 게임별 점수 상한, 점수 서버 속도 제한을 함께 추가 → 규칙을 먼저 게시한 뒤 앱 배포

성장 · 보상

레벨, 오늘의 미션, 연속 출석, 업적, 코인과 상점

9. 오늘의 미션 · 연속 출석

  • 날짜마다 정해지는 미션 3개. 모두 깨면 도장 1개(+100 XP, 코인 보너스)
  • 미션 종류: 플레이 N판클리어N점 이상N초 버티기
  • 예: “수박 게임 2,000점 이상”, “FRUIT DASH 20초 버티기”, “과일 피아노 한 곡 완주하기”
  • 새 게임은 출시 다음 날부터 미션 후보에 들어감
  • 매일 한 판씩 하면 연속 일수가 쌓임. 3 · 7 · 30일 업적
  • 연속 출석 알림: 설정 → 알림에서 켜면(로그인 필요) 그날 아직 안 했을 때 저녁 8시에 “오늘 한 판 해요!” 웹 푸시. 아이폰 · 아이패드는 홈 화면 앱에서만

12. 칭호 · 명예의 전당 · 프로필

칭호

업적 칭호나 상점에서 산 칭호를 달면 이름 옆과 랭킹에 보입니다.

명예의 전당

지난주 게임별 1등은 왕관과 “주간 챔피언” 칭호. 랭킹의 명예의 전당 탭에서 최근 8주 1등을 봅니다.

프로필 카드

닉네임 · 과일 아바타 · 테두리 · 칭호 · 레벨 · 게임별 최고 기록. 로그인하지 않아도 닉네임과 아바타를 정할 수 있습니다.

기록 그래프

최근 7일 판 수 · 플레이 시간 · 게임별 최고 점수(이 기기 기준), 최근 플레이 목록.

소셜 · 운영

계정과 동기화, 랭킹, 친구 · 선물 · 대결, 관리자 기능

13. 계정 · 기록 동기화

상태저장 위치
로그인 안 함설정 · 업적 · 통계 · 최근 플레이 · 미션 진행을 이 브라우저에 저장
Google 로그인클라우드 문서 users/{uid} 하나에 프로필 · 통계 · 업적 · 설정 · 인벤토리 · 스테이지
  • 로그인하면 기기 기록과 클라우드 기록을 항목마다 큰 값으로 합칩니다. 코인은 번 양 · 쓴 양이 늘기만 해서 기기끼리 안전하게 합쳐집니다.
  • 게임 결과는 트랜잭션으로 저장해 여러 기기에서 동시에 해도 덮어써지지 않습니다.
  • 로그아웃하면 다른 계정과 섞이지 않게 기기 기록을 비우고, 다시 로그인하면 복원합니다.
  • 최근 플레이 목록과 미션 진행은 기기에만 둡니다.

14. 랭킹

  • 랭킹 게임 8종마다 오늘 · 이번 주 · 전체 순위 (한국 시간 자정 · 월요일 기준)
  • 보드 경로: leaderboards/{게임}_{all | d<일 번호> | w<주 번호>}/scores/{uid}
  • 로그인하면 판이 끝날 때 최고 점수가 자동으로 올라가고, 결과 화면에 순위 표시
  • 공개되는 정보는 닉네임 · 아바타(기본이면 Google 사진) · 점수 · 칭호 · 테두리뿐
  • 점수는 정수, 게임별 상한 이하, 올라갈 때만(3초에 한 번까지) 바뀜. 오늘 · 어제 · 이번 주 · 지난주 · 전체 보드에만 기록
  • 욕설 · 성적인 닉네임은 정할 수 없고, 남의 이름에 있으면 *로 가림. 운영진처럼 보이는 이름과 차단 계정은 올라가지 않음
  • 운영진 기록에는 파란 체크와 파란 칭호 배지

15. 친구 · 코인 선물 · 접속 표시

  • 로그인하면 공개 프로필과 8자리 친구 코드가 생깁니다. 코드나 랭킹에서 이름을 눌러 요청 → 상대가 수락
  • 친구에게 코인을 하루 5번, 한 번에 300코인까지. 보낸 사람의 쓴 코인이 같은 쓰기에서 금액만큼 늘어야 하고, 받는 사람이 선물함에서 한 번만 받음
  • 관리자는 하루 20번, 최대치까지 보내며 코인이 줄지 않음
  • 친구 목록 · 프로필에 온라인 여부와 마지막 접속 시간. 앱이 앞에 있는 동안 1분마다 기록, 친구와 운영진만 읽음. 설정 → 친구에서 끄면 기록을 지움

16. 친구 대결

  • 결과를 공유하면 같은 판(같은 시드)으로 도전하는 링크(#c=…)가 붙습니다.
  • 링크를 연 친구가 점수를 넘으면 “도전 성공!”과 업적
  • 수박 게임은 떨어지는 과일 순서, 과일 퍼즐은 판 배치가 시드로 정해짐. 과일 자르기 링크에는 난이도도 실림
  • 결과 이미지는 공유 시트나 클립보드로 보냄

17. 관리자 기능

관리자 화면 (상단 방패 버튼)

  • 오늘 플레이어 · 판 수 통계
  • 유저 관리: 모든 유저 검색 · 필터 · 정렬, 실제 닉네임 · 친구 코드 · 최고 기록 · 마지막 접속 · 오늘 판 수, 차단 · 해제 · 랭킹 기록 삭제
  • 유저 꾸미기 변경: 관리자가 바꾼 모습이 그 플레이어 기기에 반영
  • 신고 · 의견 처리, 차단 관리. 랭킹 창에서도 기록 삭제 · 차단

권한 구조

  • 관리자 목록은 서버 쪽 설정 문서에 있고, 공개 저장소에는 계정 정보가 없습니다.
  • 설정 → 운영진에서 관리자 추가(최대 30명). 맨 앞의 소유자는 자리를 유지하고, 소유자만 관리자를 뺄 수 있습니다.
  • 운영진 시리즈 staff_* 55종은 관리자만 씀. 관리자는 코인 · 수박 아이템 무한, 업적 전부 달성 상태
  • 프리즘(RGB) 테두리 선물: 관리자가 플레이어에게 줄 수 있는 특별 테두리
  • QA 모드: 설정 → 운영진에서 켜면 일반 사용자처럼 테스트(무한 코인 · 운영진 물건 · 관리자 버튼 꺼짐, 로비에 QA 표시)

신고(랭킹 깃발 버튼)는 한 사람이 같은 기록에 한 번, 의견 보내기는 5분에 한 번이고 관리자만 읽습니다(로그인 필요).

19. 점수 검증

  1. 판 시작로그인한 플레이어는 서버에서 판 티켓을 받습니다. 무료 인스턴스가 잠들어 있을 수 있어 로그인할 때 미리 깨웁니다.
  2. 판 종료점수 · 걸린 시간 · (퍼즐은) 시드와 둔 수를 서버로 보냅니다.
  3. 서버 검사과일 퍼즐은 시드와 수로 점수를 그대로 다시 계산. 실시간 게임은 티켓으로 잰 실제 시간 대비 점수가 게임별 이론상 최대 속도를 넘지 않는지 봅니다.
  4. 서명 · 등록믿을 만한 판에만 서명(proof)을 붙이고, DB 보안 규칙이 클라이언트가 읽을 수 없는 키로 서명을 다시 계산해 맞을 때만 랭킹에 씁니다. 2026-10-20부터 서명 없는 점수는 올라가지 않습니다.

점수 확인은 최대 90초까지 기다립니다. 과일 그리기는 랭킹이 없어 검증 대상이 아닙니다.

21. 설치 · 오프라인 · 알림

  • 홈 화면에 설치 가능. 한 번 열면 앱 파일을 캐시해 인터넷 없이 플레이(로그인 · 랭킹 제외). 이모지 그림은 미리 받아 두지 않음
  • 배포 때 캐시 목록을 빌드가 채워 새 버전을 받음
  • 연속 출석 알림: 브라우저의 푸시 구독 · 마지막으로 한 날 · 연속 일수를 발송기의 공개 키로 봉인해 저장. 알림을 끄거나 로그아웃하면 지움
  • 키를 바꾸면 앱이 다음에 열릴 때 새 키로 다시 구독 · 봉인

22. 사운드 · 설정 · 접근성

  • 사운드: 게임마다 다른 배경음악과 효과음을 브라우저에서 직접 합성. 배경음악 · 효과음 볼륨 따로
  • 설정: 라이트 · 다크 · 시스템 테마, 볼륨, 연출, 휴대폰 진동, 고대비 카드, 카드 크기, 앱 설치, 데이터 초기화
  • 접근성: 운영체제 “동작 줄이기” 존중, 키보드만으로 모든 메뉴
  • 크레딧: 스크립트로 움직이는 엔딩 크레딧(탭 일시정지 · 길게 눌러 빨리 감기), 업데이트 발자취
  • 약관: 로비 아래와 설정에서 이용약관 · 개인정보 처리방침. 데이터 처리가 바뀌면 약관과 패치노트를 함께 고침

23. 배포 · 테스트

  • main에 push하면 두 곳에 자동 배포
    • 메인 서버 — 설치 후 자동 빌드, 앱 파일 + 점수 API. 정적 사이트가 아니라 웹 서비스여야 함
    • 웹 페이지 eunyool10.github.io/FruitArcade — 타입 검사와 자동 테스트가 통과해야 배포. 점수 확인은 메인 서버로
  • 무료 인스턴스는 한동안 접속이 없으면 잠들어 첫 접속에 약 50초
  • 보안 규칙은 자동 배포되지 않음. 바꾸면 규칙 테스트를 돌리고, 새 랭킹 게임처럼 앱이 의존하는 변경은 규칙을 먼저 게시
  • 로그인을 쓰는 두 도메인은 인증 승인 도메인에 등록되어 있어야 함

테스트

  • 타입 검사
  • 자동 테스트: 수박 물리, 점수 서버 검사, 상점 · 스킨 · 그림 목록, 업적 수, 그리기 싱크율
  • 규칙 테스트: 보안 규칙 시나리오 묶음(배포 없이 실행)
  • 로컬 에뮬레이터 모드: 가짜 로그인으로 랭킹 · 점수 검증까지 시험(실제 빌드에는 포함 안 됨)
