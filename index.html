주식 뉴스 트레이딩

실시간 뉴스와 시장 흐름을 기반으로 한 투자 시뮬레이션 게임

1. 프로젝트 개요

경제 뉴스와 시장 변동성을 기반으로 투자 전략을 세우는 웹 시뮬레이션 게임. 플레이어는 제한된 자금 안에서 종목을 매수·매도하며 최종 목표 자산 달성을 노립니다.

2. 기술 조건

HTML5 CSS3 Vanilla JS 프레임워크 미사용
  • 클라이언트 사이드 실행
  • 순수 정적 웹 프로젝트
/project
 ├── index.html
 ├── style.css
 └── script.js

6. 뉴스 시스템

매 라운드마다 경제 뉴스가 무작위로 생성되어 특정 종목의 가격 변동성에 영향을 줍니다.

호재 (Positive) 악재 (Negative) 중립 (Neutral) 
{
  headline: "삼성전자 AI 반도체 공급 확대",
  type: "positive",
  target: ["SAMS"],
  effect: [0.06, 0.10]
}

8. 주가 변동 알고리즘

실시간 틱 시스템

price = price * (1 + newsImpactRate)
