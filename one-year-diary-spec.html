프로젝트 개요

지금의 나와 일 년 뒤의 나를 잇는 짧은 일기

기록의 방식

사용자는 Google 계정으로 로그인한 뒤 오늘 하루를 기억할 문장 하나를 남깁니다. 날짜별로 하루 한 건만 작성하며, 문장은 최대 180자입니다. 기록 목록에는 작성일과 공개 예정일이 표시됩니다.

아직 공개되지 않은 문장의 본문은 화면에서 가려지고, 공개일이 지나면 목록에서 다시 읽을 수 있습니다. 오늘 이미 기록을 남겼다면 해당 날짜의 입력과 저장은 비활성화됩니다.

주요 기능

로그인, 날짜별 기록, 1년 잠금 해제

사용 흐름

  1. Google 로그인Firebase Authentication을 통해 사용자를 확인합니다.
  2. 오늘의 문장 작성최대 180자의 문장을 입력하고 하루 한 번 저장합니다.
  3. 계정에 동기화기록은 사용자 계정에 연결되어 다른 기기에서도 불러올 수 있습니다.
  4. 일 년 뒤 다시 읽기공개 예정일이 되면 잠겨 있던 문장의 본문을 읽을 수 있습니다.

화면 구성

  • 오늘의 한 문장: 오늘 날짜, 입력란, 글자 수, 저장 버튼
  • 기록 목록: 작성일, 공개 예정일, 잠금 또는 공개 상태
  • 계정 영역: 로그인 상태, Google 로그인 및 로그아웃
  • 반응형 화면: 휴대폰과 데스크톱에서 사용할 수 있는 웹 화면

저장과 공개 기준

사용자별 Firestore 경로와 서버 보안 규칙

데이터 구조

Firestore 기록 경로는 users/{uid}/days/{YYYY-MM-DD}이며, 날짜 메타데이터와 잠긴 본문을 분리해 저장합니다. 본문은 해당 기록의 sealed/letter 문서에 보관합니다.

  • 로그인한 사용자는 자신의 UID 경로에만 기록할 수 있습니다.
  • 보안 규칙은 기록 소유자와 작성 시점의 잠금 상태를 확인해야 합니다.
  • 본문 읽기는 서버에 저장된 공개 시각 이후에 허용되어야 합니다.
  • 클라이언트 화면의 흐림 처리만으로는 보안을 보장하지 않으며, Firestore 규칙이 본문 접근을 제한합니다.

앱은 작성 시각에서 달력상 1년을 계산하고, Firestore 서버 규칙의 최소 365일 잠금 검증을 통과하도록 공개 시각에 5분의 여유를 더합니다. 따라서 실제 공개는 작성일로부터 1년 후 최대 약 5분 늦을 수 있습니다.

현재 앱 안내

일기 앱은 Firebase 웹 설정을 불러와 Google 로그인과 Firestore 저장을 사용합니다. Firebase Console에서 Google 인증 제공자, 승인된 도메인, Firestore 데이터베이스 및 보안 규칙을 설정해야 동기화와 잠금 해제가 동작합니다.
